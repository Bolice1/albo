# Integrations

**Status:** Proposed inventory — each integration needs a separate security and data-contract review

Potential integrations include weather and climate data, air quality, maps/geocoding, health-device platforms, electronic health records, messaging, identity, and object storage.

All integrations must use adapters, timeouts, retries with bounds, provenance, consent checks, rate limits, secret management, and a documented fallback. The proposal's linked design folder is an external reference and must not be treated as an implementation contract until reviewed.
