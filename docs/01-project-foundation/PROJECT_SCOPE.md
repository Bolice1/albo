# Project scope

**Status:** Proposed

## Initial scope

- Documentation-first project foundation
- Responsive web application
- Identity, consent, roles, audit, and profile foundations
- Selected citizen and provider journeys
- Relational health, facility, and environmental data foundations
- Explainable rule-based and weighted risk indicators
- Safe AI assistant boundary and escalation behavior
- Initial notification, facility, map, and report foundations

## Later scope

- Native mobile applications and wearable integrations
- Advanced machine learning after data quality and clinical validation
- Electronic health-record interoperability such as FHIR after partner requirements
- Independent service extraction when scale or ownership justifies it

## Explicitly out of scope initially

- Autonomous diagnosis or treatment decisions
- Training a proprietary large language model
- Real patient data in local development or demos
- Kubernetes or many microservices without an operational need
