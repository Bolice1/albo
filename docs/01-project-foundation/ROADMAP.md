# Roadmap

**Status:** Proposed — dates and ownership require agreement

1. **Foundation:** approve users, vision, requirements, scope, and success measures.
2. **Architecture:** approve boundaries, stack, data model, API conventions, and security baseline.
3. **Core platform:** implement identity, consent, roles, audit, profiles, and selected workflows.
4. **Preventive intelligence:** implement transparent rules and weighted scoring with synthetic data.
5. **Services:** prioritize assistant, notifications, environmental data, maps, and provider workflows.
6. **Validation:** test usability, security, privacy, reliability, AI behavior, and clinical safety.
7. **Production readiness:** establish deployment, monitoring, backups, incident response, and governance.

Each phase requires documentation, review, implementation, tests, and recorded decisions before it is complete.
