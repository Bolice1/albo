# Albo

Albo is an AI-powered preventive digital health hub designed to help people identify possible health risks earlier and connect with appropriate healthcare services.

## Project status

Albo is currently in the documentation and architecture foundation phase.

## Important principles

- Never commit credentials or real patient data.
- Use synthetic or properly de-identified data during development.
- Treat AI output as a risk indicator, not a diagnosis.
- Respect consent, privacy, and authorization.
- Keep implementation and documentation synchronized.
- Record significant architectural decisions.
